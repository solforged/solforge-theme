# Solforge Light

An Omarchy theme after [solforged.io](https://solforged.io): a vellum sheet on
an oxblood desk, iron-gall ink, gilt and rubric red, with wireframe backgrounds
after Leonardo's notebooks.

`colors.toml` is the palette source of truth; Omarchy renders the terminal,
Hyprland, Neovim and shell configs from it. The palette and backgrounds are
generated by `generate.py` one directory up.
